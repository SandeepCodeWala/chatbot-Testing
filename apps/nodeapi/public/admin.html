How the System Prompt Works

Understanding sections and hard rules

SCOPE section
Defines what the AI is allowed to help with. The AI will only act on topics listed here.
OUT OF SCOPE — hard rule
Forces the AI to refuse any question outside the scope. This is why Test Chat rejects questions about plans, weather, etc. To allow broader topics, remove or soften this section.
AUTH RULES & CONFIRMATION
Guards login-protected APIs and requires user confirmation before any data-changing action (update, delete, signup).

Edit the prompt above and click Save Changes. New behavior takes effect within 60 seconds — no deployment needed.
