Embeddable Chat Widget

Add the chatbot to any website with a single <script> tag. The floating button appears in the bottom-right corner.

Option 1 — Config Object

Full configuration via window.ChatWidgetConfig

Set all options in a global config object before loading the widget script. Best when you need full control.

<script>
  window.ChatWidgetConfig = {
    serverUrl: 'http://localhost:3000',   // your server URL
    app:       'vocuscustomer',           // which project / bot to load
    title:     'Customer Support',        // panel header title
    subtitle:  'We reply instantly',      // panel header subtitle
    theme:     '#2563eb',                 // accent colour (hex)
    position:  'bottom-right',            // or 'bottom-left'
    initMsg:   'Hello! How can I help?',  // first bot message
  };
</script>
<script src="http://localhost:3000/widget.js"></script>
Option 2 — data-* Attributes (simplest)

Configure directly on the <script> tag

The widget auto-detects the server URL from the script's src. Paste one line anywhere in your page.

<script src="http://localhost:3000/widget.js"
        data-app="vocuscustomer"
        data-title="Customer Support"
        data-subtitle="We reply instantly"
        data-theme="#2563eb"
        data-position="bottom-right">
</script>
Replace http://localhost:3000 with your deployed server URL (e.g. your Render URL) when going to production.
Switch Project / Bot

Different bots for different pages

Change the app value to load a different project's bot. Each app has its own APIs and system prompt.

// Available projects on this server:
// vocuscustomer  — customer support bot
// nodeapi        — Node API demo bot
// vocus          — default bot

// Use data-app to pick one per page:
<script src="http://localhost:3000/widget.js"
        data-app="nodeapi"
        data-title="NodeAPI Assistant"
        data-theme="#7c3aed">
</script>
👇 The chat widget is active on this page — click the button in the bottom-right corner to try it.
